ПЕРВАЯ ВЕРСИЯ · GODOT

Первые шаги в игре

Мы начали собирать настоящий прототип Hide & Seek на Godot. Сейчас в нём есть небольшая арена, управление персонажем, охотник, укрытия и раунд на выживание. Это ранняя тестовая версия: пока без сетевой игры, готовых скинов и финальной графики.

Состав матча

Планируем классический режим: четыре выживших против одного маньяка. Сейчас реализован только один управляемый выживший и компьютерный охотник.

Персонажи

В первой версии будут базовый выживший и базовый маньяк. Позже добавим отдельные скины и героев с уникальными способностями.

Управление

WASD или стрелки — перемещение по арене.

Укрытия

Подойди к отмеченному укрытию и нажми E, чтобы спрятаться или выйти.

Цель раунда

У тебя есть время переждать поиск охотника. Если тебя поймали — начни заново клавишей R.

Как запустить исходники:
1. Открой папку проекта по ссылке ниже на GitHub и скачай репозиторий через Code → Download ZIP.
2. Распакуй архив.
3. В Godot 4.7.2 выбери Import и укажи файл games/hide-and-seek/project.godot.
4. Нажми Run Project (▶).

Это исходный проект, а не готовый установщик или проверенная сборка для Windows/Android.
