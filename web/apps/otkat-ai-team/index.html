CONNECTIONS

Поддерживаемые провайдеры

OpenAI, Google Gemini, DeepSeek, Anthropic Claude, xAI Grok и OpenRouter. Каждый провайдер подключается отдельно серверным API-ключом.

Демо-режим не вызывает модели. Для реальной работы требуется собственный защищённый сервер, настроенные API-ключи и разрешение реальных запросов. Пять моделей и четыре проверки могут выполнять до 11 платных API-вызовов на одну задачу.

ANDROID · WINDOWS SERVER

Как запустить

Android-клиент версии 0.2.0 собран в CI. Backend запускается отдельно на Windows или Linux с Python 3.11+.

  1. Установи Android APK, открой настройки подключения и укажи HTTPS-адрес своего OTKAT AI Team API.
  2. На сервере установи зависимости из server/pyproject.toml и запусти FastAPI через Uvicorn.
  3. Добавь API-ключи только в закрытые переменные окружения сервера — не в приложение и не в браузер.
  4. Создай профили агентов с точными ID моделей, проверь каждого через «Проверить API», затем запускай команду.

Серверная версия пока предназначена для локального/частного развёртывания. Публичный многопользовательский сервис, авторизация пользователей, облачное размещение и полноценное управление секретами ещё не выпущены. Не открывай API в интернет без дополнительной защиты.
