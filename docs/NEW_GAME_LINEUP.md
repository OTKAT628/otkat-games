## Техническое устройство
- Отдельная HTML-страница каждой игры.
- Общий движок логики: `web/new-games.js`.
- Рекорды хранятся в localStorage отдельно для каждой игры.
- Управление: клавиатура для динамичных игр, экранные кнопки для Neon Depths и касания по игровому полю для Tiny Kingdoms и Cozy Valley.
- Без внешних игровых ассетов и без генерации изображений. Поле рисуется Canvas-примитивами.
