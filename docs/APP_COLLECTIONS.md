# OTKAT Games — концепции пяти приложений-сборников

## Общая продуктовая архитектура
- Пять отдельных приложений с собственными ID, страницами, иконками, настройками, прогрессом и релизами.
- Четыре мини-игры на приложение; одиночные режимы и локальные режимы на двоих там, где заявлено.
- Три уровня сложности. Для казуальных игр сложность меняет скорость, размер поля, число пар/подсказок, а не только урон.
- Offline-first: игровые раунды не зависят от сети; локальные рекорды хранятся в устройстве; service worker кеширует оболочку; серверная синхронизация — следующий этап.
- OTKAT ID необязателен для локального старта. Вход нужен только для облачной синхронизации и переноса между устройствами.
- Sync protocol: локальная outbox-очередь, UUID операции, идемпотентный API, cursor/revision, retry с backoff и разрешение конфликтов; не затирать прогресс слепой заменой.
- Никаких секретных ключей в клиентском коде.

## Приложения и мини-игры
1. **Arcade Mix** — Неонополис потерял источник энергии; игрок проходит Аркадную лигу. Neon Dodge (реакция), Sky Hop (прыжки/память), Pulse Runner (быстрые задачи), Target Blitz (мишени). В основном одиночная игра; отдельные режимы на двоих по очереди.
2. **Puzzle Lab** — лаборатория закрыла сектора; логические задачи открывают комнаты. Memory Vault, Number Flash, Pattern Finder, Quick Math. Одиночная игра и совместная/поочерёдная память.
3. **Party Duo** — турнир старой консоли. Tap Duel, Memory Race, Quick Quiz, Score Battle. Два игрока на одном устройстве, локально, без сети.
4. **Action Rush** — станция Рубеж отбивается от вышедших из-под контроля дронов. Drone Strike, Last Stand, Rapid Fire, Core Defense. Соло; кооператив на одном устройстве — этап расширения.
5. **Cozy Worlds** — остров Тихая Бухта и унаследованный домик. Garden Pairs, Fishing Time, Color Garden, Daily Calm. Спокойный одиночный режим и необязательные локальные соревнования.

## Текущая реализация прототипа
- Страницы пяти приложений, общий движок мини-игр в `web/collection-app.js`.
- Локальные рекорды/счёт в localStorage; без входа и без сервера.
- Прототипы памяти, арифметики, реакции/мишеней, локальной дуэли на одном экране и поиска пар.
- PWA manifest и service worker для кеширования оболочки; офлайн-первый запуск требует предварительного открытия сайта онлайн и проверки кеша в браузере.
- Это браузерные прототипы, не Android/Windows установщики. Синхронизация между устройствами пока не реализована.
