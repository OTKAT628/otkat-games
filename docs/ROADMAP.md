# OTKAT — план разработки

## Принципы
- Игры самостоятельные, не объединены общим игровым лором.
- Для первых игр используем Godot 4.7.2 и GDScript.
- Сайт — отдельный статический проект.
- Не публикуем фиктивные ссылки на загрузки: только проверенные сборки.

## Очерёдность
1. Hide & Seek: локальная играбельная демоверсия, одна карта, движение, укрытия, таймер и простой бот-охотник.
2. Survival: отдельный новый проект, сбор ресурсов, инвентарь, крафт и мини-игры.
3. Сайт: каталог, страницы игр, новости и загрузки.
4. Онлайн, OTKAT ID и магазин — после проверки базового игрового цикла.

## Текущий статус
- Создана начальная статическая версия сайта в `web/`.
- Сайт ещё не развёрнут на хостинге.
- Игровой проект Hide & Seek ещё создаётся.
- Survival будет начат отдельно, без переноса старого проекта.
