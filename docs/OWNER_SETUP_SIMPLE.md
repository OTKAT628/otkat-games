# Простая настройка OTKAT ID — пошагово

Это короткая инструкция для владельца. OTKAT ID пока не подключён к живому проекту; сначала нужно создать Supabase.

## Что сделать (примерно 10–15 минут)

1. Откройте https://supabase.com/ и войдите через GitHub.
2. Нажмите **New project**. Название: `otkat-id`. Выберите ближайший доступный регион. Придумайте database password и сохраните его в менеджере паролей.
3. Дождитесь запуска проекта.
4. В меню проекта откройте **SQL Editor → New query**.
5. Откройте файл [001_otkat_id.sql](../supabase/migrations/001_otkat_id.sql), скопируйте весь текст, вставьте в SQL Editor и нажмите **Run**.
6. Откройте **Project Settings → API**. Скопируйте **Project URL** и **publishable key** (если интерфейс показывает legacy anon key — его тоже можно использовать для клиентского MVP).
7. Сохраните эти два значения отдельно. Их можно передать разработчику для настройки сайта. **Не отправляйте database password и service_role/secret key.**

## Что проверить после подключения

- Зарегистрировать тестовый аккаунт.
- Выйти и войти снова.
- Проверить, что появилась строка профиля.
- Проверить, что пользователь видит только собственные облачные сохранения.
- Повторить проверку вторым аккаунтом и убедиться, что чужое сохранение недоступно.

## Важно

- В браузер, игру и APK разрешено помещать только Project URL и publishable/anon key.
- Никогда не помещайте `service_role` или secret key в сайт, APK, чат или Git.
- Применение SQL ещё не означает, что OTKAT ID уже подключён к сайту. После получения Project URL и publishable key нужно добавить клиентскую конфигурацию и проверить вход на опубликованном сайте.
- До подключения OTKAT ID все игры должны продолжать запускаться без аккаунта.
