# OTKAT Arcade Games

Девять самостоятельных 3D-игр: Hide & Seek, Survival, Arena, Forgotten, Skyrun, Racing, Space, Magic и Prehistoric.

## Сайт
- Главная: https://otkat628.github.io/otkat-games/
- Каталог: https://otkat628.github.io/otkat-games/games/
- Каждая игра имеет отдельную страницу в `web/<slug>/index.html` с сюжетом, режимами, кастомизацией и разделом установочных файлов.
- Общий браузерный 3D-прототип: `web/prototype-3d/index.html?game=<slug>`.

## Структура игр
Каждая игра планируется как отдельный 3D-проект. У каждой собственная сюжетная линия, обычный режим, отдельная мини-игра и косметическая кастомизация персонажа, предметов и окружения. Прототип использует Three.js через CDN и требует подключения к интернету.

## Сборки
Windows EXE/ZIP и Android APK пока не созданы и не опубликованы. На страницах игр установочные файлы будут размещены после экспорта и проверки. Не считать ZIP репозитория установщиком.

## Публикация
GitHub Actions workflow `.github/workflows/deploy.yml` публикует папку `web/` на GitHub Pages. Не меняйте видимость репозитория ради публикации без отдельного решения.
