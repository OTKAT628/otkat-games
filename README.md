# OTKAT — независимая игровая студия

Начинаем разработку с нуля. Старые игровые проекты не переносим.

## Сайт
- Главная: `web/index.html`
- Hide & Seek: `web/hide-and-seek/index.html`
- Survival: `web/survival/index.html`
- Стили: `web/styles.css`

## Первые игры
- **Hide & Seek** — первый прототип на Godot 4.7.2 / GDScript.
- **Survival** — отдельный проект, следующий этап разработки.

## План
См. `docs/ROADMAP.md`. Ссылки на скачивание появятся только после сборки и проверки Windows/Android версий.

## Статус
Сайт — начальная статическая версия, пока не опубликован. Игровые проекты ещё предстоит создать и проверить в Godot.
