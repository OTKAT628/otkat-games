# OTKAT Arcade Games

Десять игровых проектов: девять 3D-приключений и новая гоночная игра Driftline: Apex Circuit.

## Сайт
- Главная: https://otkat628.github.io/otkat-games/
- Каталог: https://otkat628.github.io/otkat-games/games/
- Отдельные страницы: `web/<slug>/index.html` — сюжет, обычный режим, мини-игра, кастомизация и статус установщиков.
- Общий браузерный 3D-прототип: `web/prototype-3d/index.html?game=<slug>`.

## Прототип
Общий Three.js прототип содержит 3D-сцену, WASD/стрелки, камеру, сбор объектов, выбор игры, обычный и мини-режимы. Для игр добавлены разные управляющие действия и испытания: маскировка, поддержание огня, атака, последовательности памяти/рун, прыжки, нитро, стыковка и скрытное движение. Есть базовый выбор скина персонажа, предметов и окружения. Three.js загружается с CDN, поэтому для прототипа нужен интернет.

Это ранний общий браузерный прототип, а не девять законченных игр: индивидуальные полноценные уровни, модели, анимации, AI, сетевой режим, сохранения и полные игровые циклы ещё предстоит разработать и протестировать.

## Установщики
Windows EXE/ZIP и Android APK пока не созданы и не опубликованы. На каждой отдельной странице предусмотрен раздел для будущих установщиков. Файлы появятся только после экспорта и проверки. ZIP исходников репозитория не является установщиком.

## Публикация
GitHub Actions workflow `.github/workflows/deploy.yml` публикует папку `web/` на GitHub Pages. Не меняйте видимость репозитория ради публикации без отдельного решения.


## Driftline: Apex Circuit
- Отдельная гоночная игра: `web/driftline/index.html`.
- Браузерный прототип с одиночным заездом против CPU и локальным режимом для двух игроков на одном устройстве.
- Четыре вымышленные марки/модели, выбор цвета кузова, оформление/скин и диски.
- Улучшения двигателя, управления и нитро за тестовые кредиты.
- Три предустановленные трассы, редактор собственной сеточной трассы и локальная таблица рекордов.
- Прогресс и рекорды сохраняются в localStorage этого браузера. Онлайн-мультиплеер, глобальный рейтинг, облачная синхронизация и установщики ещё не реализованы.

## Общие функции 3D-проектов
- На страницах девяти 3D-игр добавлены общие меню косметики персонажа, выбора окружения, локального редактора карты, режима для двух игроков и таблицы рекордов.
- Настройки сохраняются локально. Общий 3D-прототип поддерживает локальный совместный сбор предметов с клавиатурой WASD + стрелки; онлайн-игра с друзьями пока отсутствует.
- Полная интеграция пользовательских карт с каждым индивидуальным уровнем и отдельные игровые деревья улучшений — следующие этапы разработки.
