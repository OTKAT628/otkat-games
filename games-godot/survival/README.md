# OTKAT Survival — 3D first playable slice

Godot 4.4.1 / C# / .NET 8.

## Implemented
- 3D island arena, third-person camera, player movement and collision.
- Procedurally placed trees, rocks and berry resources.
- Resource gathering, hunger, health, day progression and day/night light cycle.
- Shelter crafting and local save/load for position, inventory and survival stats.

## Not yet implemented
This is a single-player vertical slice. Co-op networking, world persistence for built structures/resources, enemies/wildlife, full crafting tree, story campaign, touch controls and Android export remain. Do not list as a finished release yet.

Build: `dotnet build OTKAT.Survival.csproj -c Release`.
