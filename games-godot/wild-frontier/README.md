# OTKAT Wild Frontier

Godot 4 / GDScript top-down survival prototype. Includes movement, resource gathering, food/hunger, health, day progression and crafting a shelter.

Controls: WASD / arrow keys to move, E gather, F eat, C craft shelter. Run with Godot 4 by importing the project and pressing F5.

This is a playable survival slice, not a finished open-world release. It still needs enemies/wildlife, quests, world generation, saving, sound/art, localization, balancing and Android/Windows QA.
