# OTKAT World Detective — Android edition

Godot 4.4.1, GDScript, native Android export.

## First slice
- Five-round offline city-guessing game.
- Eight clue sets from Europe, Asia, Africa, North and South America.
- Four city choices, immediate feedback and score.
- Restartable session and responsive touch-friendly controls.
- No account, location permission, external map imagery or network dependency.

## Build
Open this folder's `project.godot` in Godot 4.4.1 standard (non-.NET) and export using the Android preset in `export_presets.cfg`.

This is an early offline prototype, not a finished geography game. It has no Street View/panorama, map navigation, multiplayer, public leaderboards or user-generated maps. The Android package must pass CI export and real-device installation/gameplay tests before being listed as a released download.
