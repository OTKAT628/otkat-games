# OTKAT Party Circuit

Godot 4 / GDScript local party game. Supports 2–4 players on one device, rounds, score tracking, reaction, arithmetic, memory and attention challenges.

Run with Godot 4: import this folder and press F6/F5. This is the first playable implementation slice, not a network multiplayer release. Online matchmaking, accounts, controller remapping, audio/animation and device QA remain separate work.
