# OTKAT Hide & Seek — native 3D foundation

Engine target: Godot 4.7.2 (GDScript), mobile-friendly Compatibility renderer.

This is the first native 3D vertical-slice foundation, separate from the legacy 2D experiment and browser mock-up. Open `project.godot` in Godot 4.7.2 and run the main scene.

## Implemented in this source slice
- Procedurally assembled abandoned shopping mall interior with an atrium, closed shop fronts, columns, debris, damaged fixtures and varied disguise props.
- First-person survivor controller with keyboard/mouse and basic two-zone touchscreen movement/look input.
- Touchscreen disguise button and keyboard interaction.
- Hunter patrol/chase/investigation state machine with basic obstacle steering.
- Preparation countdown, hunt timer, caught/win states and round restart.

## Not implemented yet
This is not the finished game. It does not yet include multiplayer, the six complete worlds / 72 production maps, final character art, animation sets, weapon combat, inventory, account sync, progression, achievements or production-ready navigation. These are subsequent implementation milestones and must be built and tested before any release package is produced.

## Current playable scope
One local single-player test map: Apocalypse world — abandoned shopping mall. Art is procedural blockout geometry and materials, not final authored assets.
